# Facturette

A small single-page app to generate invoices for French users in the
[Factur-X](https://fnfe-mpe.org/factur-x/) format, entirely in the browser.

> **Status:** project scaffold. Invoice editing and Factur-X generation are not implemented yet.

## Stack

- [Bun](https://bun.sh) for package management and scripts
- [Vite](https://vite.dev) + [React](https://react.dev) + TypeScript (strict)
- [TanStack Router](https://tanstack.com/router) with file-based routing (`src/routes`)
- [Tailwind CSS](https://tailwindcss.com) v4
- [Biome](https://biomejs.dev) for linting and formatting

## Getting started

```sh
bun install
bun run dev
```

| Script              | What it does                                  |
| ------------------- | --------------------------------------------- |
| `bun run dev`       | Start the Vite dev server                     |
| `bun run build`     | Typecheck, then build the static SPA to `dist/` |
| `bun run preview`   | Serve the production build locally            |
| `bun run typecheck` | Run `tsc --noEmit`                            |
| `bun run check`     | Lint and format check (Biome)                 |
| `bun run check:fix` | Apply Biome fixes                             |

## Output

`bun run build` produces a fully static site in `dist/`. Host it on any static provider, with
one requirement: unknown paths must fall back to `index.html`, because routing happens on the
client.

`src/routeTree.gen.ts` is generated by the TanStack Router plugin and is committed on purpose, so
that `typecheck` works on a fresh clone. Do not edit it by hand.
